# DRAGNET GDPR Self-Assessment

A preliminary educational privacy assessment by David Gill of the DRAGNET news-research MVP, completed during Ironhack's AI Consulting & Integration course.

## Start here

[Read the assessment](DRAGNET_GDPR_Self_Audit_David_Gill.md).

The document examines personal-data flows, service-provider roles, retention, data minimisation, transparency, rights handling and the circumstances that would require a fresh risk assessment as the project grows.

## Relationship to the project

The assessed workflow connects Telegram, n8n, a locally operated research application, GNews and OpenAI. The assessment distinguishes documented behaviour from missing provider or operational evidence.

See the [main DRAGNET repository](https://github.com/DavidGillAI/DRAGNET_Autonomous_News_Verification_Agent) for implementation and related evaluations.

## Scope and status

This is a historical self-assessment of a small academic MVP. It is not legal advice, a certification or a guarantee of present compliance. Deployment, provider terms, user population and data handling can change, so conclusions should be reviewed against the actual system before wider operation.

No application runs from this repository. The Markdown assessment can be read directly on GitHub.
